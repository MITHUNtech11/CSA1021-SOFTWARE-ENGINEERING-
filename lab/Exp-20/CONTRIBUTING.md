# Contributing to CSA1021 Omnichannel Fulfilment Platform

## Git Flow & Branching Policy
- `main`: Production release branch. Strictly protected; requires 2 reviews.
- `develop`: Integration branch for active sprint features.
- `feature/*`: Short-lived feature branches branched from `develop`.
- `bugfix/*`: Defect resolution branches.

## Commit Message Standards
Follow Conventional Commits:
- `feat(scope): add new feature`
- `fix(scope): resolve bug`
- `test(scope): add automated unit tests`
